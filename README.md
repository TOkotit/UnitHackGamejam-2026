Шутер платформер с мехникой разрезания уровня пополам

Вы находитесь на съёмках очередного боевика из 80-х, монтируйте кадр прямо во время игры, чтобы удачно снять сцену
При разрезании уровня части менются местами и склеиваются обратно

Управление:
A - идти влево
D - идти вправо
Space - прыжок
ЛКМ - удар мачете и парирование
С - перейти в режим монтирования
Q - рестарт уровня

Режим монтирования:
ЛКМ - разрезать уровень по линии
R - изменить направление разреза
C - выйти из меню
